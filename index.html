Manage your Minecraft servers.
All in one place.

Deadly Server Manager is a native Windows application for importing, creating, running, monitoring, updating, backing up, and managing local Minecraft servers. It works locally without requiring a cloud account.

Built for server management

Tools for common Minecraft server tasks, with verification and safeguards built into important operations.

01

Server control

Create and import servers, switch between registrations, and start, restart, or stop supported server processes.

02

Plugin browser

Discover plugins through supported providers, inspect project information, check updates, and manage staged installations.

Backups & restore

Content and server integrations

Deadly Server Manager connects to supported Minecraft services for server software and plugin discovery.

Modrinth

Provider integration for plugin discovery and supported project/version information.

CurseForge

Plugin discovery using a user-provided API key stored through the application's credential manager. API access remains subject to CurseForge approval and terms.

SpigotMC / Spiget

Plugin discovery with official-page fallbacks where provider data is unavailable.

PaperMC

Paper server builds through the official Fill API, with download verification and Java requirement checks.

Playit.gg

Management of the official Playit agent and display of available tunnel addresses.

Local workspace

Server files, databases, backups, restore points, and application data remain in the configured local workspace.

Native, local-first architecture

The desktop interface is built with React and TypeScript. The Tauri application uses a Rust backend and SQLite database for local application data.

Tauri 2React 19TypeScriptRustSQLite

Safety-conscious operations

Downloads are staged and verified. Backups are checked against manifests. Destructive actions require confirmation, and credentials are protected using Windows DPAPI.

Actual live data is shown when available. Unavailable information is not presented as if it were real.
